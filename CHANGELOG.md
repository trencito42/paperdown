# Changelog

## 0.1.0-beta — 2026-03-20

### Added

- Initial WinUI 3 desktop application with editor, preview, and PDF export.
- Markdig-based Markdown pipeline with HTML sanitization.
- Five print themes and Twemoji-based emoji rendering for PDF output.
- Branding and page settings dialogs, preferences, draft recovery.
- CLI `convert` command sharing the core renderer and PDF engine.
- GitHub Actions Windows build workflow and xUnit test suite.
